LiquidGlassKit은 Liquid Glass 표면과 컨트롤을 쓰면서도 Liquid Glass가 없는 시스템을 계속
지원하려는 앱을 위한 SwiftUI 패키지입니다. iOS, macOS, tvOS, watchOS 26에서는 SwiftUI의 네이티브
`glassEffect`로 그리고, 이전 버전(iOS 17, macOS 14, tvOS 17, watchOS 10까지)과 visionOS에서는
색조, 가장자리 하이라이트, 그림자를 더한 `Material` 블러로 그립니다. 모든 OS에서 같은 코드를
작성하면 됩니다.

| 갤러리(라이트) | 갤러리(다크) | 네이티브와 대체 렌더링 |
| --- | --- | --- |
| ![갤러리, 라이트](docs/images/gallery-light.png) | ![갤러리, 다크](docs/images/gallery-dark.png) | ![네이티브와 대체 렌더링](docs/images/compare-light.png) |

## 주요 기능

- **모디파이어 하나, 렌더링 경로 둘** — `glassSurface`는 실행 시점에 네이티브 글래스와
  `Material` 기반 대체 렌더링(fallback) 중 하나를 고릅니다. 모든 곳에서 같은 모습을 원하면
  `glassRenderingMode(.fallback)`으로 대체 렌더링을 강제할 수 있습니다.
- **바로 쓰는 컨트롤** — 버튼, 카드, 텍스트 필드, 검색 막대, 떠 있는 탭 막대, 내비게이션 막대,
  하단 시트(bottom sheet)를 제공하며 모두 `glassSurface`로 그립니다.
- **테마** — `GlassTheme`은 뷰 계층 전체의 머티리얼, 모양, 그림자, 가장자리 하이라이트를
  정합니다. 각 컴포넌트에는 여전히 개별 머티리얼을 지정할 수 있습니다.
- **손쉬운 사용** — '투명도 줄이기'(Reduce Transparency)가 켜져 있으면 대체 렌더링은 불투명한
  배경을 그립니다. 장식용 아이콘은 VoiceOver에서 숨겨지고, 탭 막대는 선택된 탭을 알려 주며, 시트는
  이스케이프 제스처로 닫힙니다.
- **이름 충돌 없음** — API가 SwiftUI 자체 이름(`glassEffect`, `GlassEffectContainer`,
  `GlassButtonStyle`)을 피하므로 두 모듈을 한 파일에서 import할 수 있습니다.
- **테스트된 렌더링** — Swift Testing 테스트 스위트가 CI의 macOS와 iOS 시뮬레이터에서 실행되며,
  오프스크린 렌더링으로 대체 경로에서 모든 컴포넌트가 올바른 머티리얼로 글래스를 그리는지
  확인합니다.

## 빠른 시작

**1. 패키지 추가**

Xcode에서 **File › Add Package Dependencies…**를 선택하고 저장소 URL을 입력하세요.

```text
https://github.com/muhittincamdali/LiquidGlassKit.git
```

의존성 규칙은 2.0.0부터 시작하는 **Up to Next Major Version**으로 두고 **Add Package**를
클릭하세요. 다음 대화 상자에서 `LiquidGlassKit`을 추가할 앱 타깃을 선택하고 **Add Package**를
한 번 더 클릭하세요.

**2. 모듈 가져오기**

```swift
import LiquidGlassKit
```

**3. 사용하기**

`ContentView.swift`의 내용을 아래 뷰로 바꾸고 앱을 실행하세요(⌘R). 그라데이션 위에 글래스
카드와 글래스 버튼이 나타납니다.

```swift
import LiquidGlassKit
import SwiftUI

struct ContentView: View {
    var body: some View {
        ZStack {
            LinearGradient(colors: [.indigo, .pink], startPoint: .top, endPoint: .bottom)
                .ignoresSafeArea()
            VStack(spacing: 16) {
                GlassCard {
                    Label("Hello, glass", systemImage: "sparkles")
                }
                GlassButton("Tap me", systemImage: "hand.tap") {}
            }
        }
    }
}
```

```text
https://github.com/muhittincamdali/LiquidGlassKit.git
```

또는 `Package.swift`의 `dependencies`에 추가하세요.

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/LiquidGlassKit.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "LiquidGlassKit", package: "LiquidGlassKit")
    ])
]
```

## 사용법

글래스는 뒤에 무언가가 있어야 보이므로 이 뷰들은 이미지, 그라데이션, 스크롤되는 콘텐츠 위에
배치하세요. 이 README의 뷰는 테스트 스위트에서 컴파일하고 렌더링합니다
([`ReadmeExamplesTests.swift`](Tests/LiquidGlassKitTests/ReadmeExamplesTests.swift)).

### 어떤 뷰든 글래스 위에 올리기

```swift
import LiquidGlassKit
import SwiftUI

struct NowPlayingBadge: View {
    var body: some View {
        Label("Now Playing", systemImage: "music.note")
            .padding()
            .glassSurface(.tinted(.purple), in: .capsule)
    }
}
```

머티리얼: `.clear`, `.frosted`, `.tinted(Color)`, `.dark`. 모양: 둥근 사각형, 캡슐, 원,
모서리마다 다른 반경.

### 컨트롤로 폼 만들기

```swift
struct SignInForm: View {
    @State private var email = ""
    @State private var query = ""

    var body: some View {
        VStack(spacing: 16) {
            GlassSearchBar(text: $query, prompt: "Search")
            GlassTextField("Email", text: $email, systemImage: "envelope")
            GlassCard {
                Text("We will send you a sign-in link.")
            }
            HStack {
                Button("Cancel", role: .cancel) {}
                    .buttonStyle(.liquidGlass(size: .compact))
                GlassButton("Continue", systemImage: "arrow.right", material: .tinted(.blue)) {}
            }
        }
        .padding()
    }
}
```

### 탭 막대를 띄우고 시트 열기

```swift
enum Screen: Hashable { case home, search, profile }

struct RootView: View {
    @State private var screen = Screen.home
    @State private var showsSheet = false

    var body: some View {
        ZStack(alignment: .bottom) {
            Color.indigo.ignoresSafeArea()
            GlassTabBar(selection: $screen) {
                GlassTab("Home", systemImage: "house", value: Screen.home)
                GlassTab("Search", systemImage: "magnifyingglass", value: Screen.search)
                GlassTab("Profile", systemImage: "person", value: Screen.profile)
            }
            .padding()
        }
        .glassSheet(isPresented: $showsSheet) {
            Text("Sheet content").padding()
        }
    }
}
```

`GlassTabBar`는 모든 `Hashable` 선택 값과 함께 동작하며, 빌더는 `if`와 `for`를 지원합니다.
시트는 아래로 끌어내리거나, 어두워진 배경을 탭하거나, 손쉬운 사용의 이스케이프 제스처로
닫힙니다. tvOS에서는 사용할 수 없습니다.

### 모든 뷰에 테마를 적용하고 렌더링 경로 선택하기

```swift
struct ThemedApp: View {
    var body: some View {
        RootView()
            .glassTheme(GlassTheme(material: .tinted(.indigo), shape: .roundedRectangle(cornerRadius: 12)))
            .glassRenderingMode(.automatic) // or .fallback to use the Material look everywhere
    }
}
```

### API 개요

| API | 하는 일 |
| --- | --- |
| `glassSurface(_:in:interactive:)` | 어떤 뷰든 뒤에 글래스를 깝니다. OS 26에서는 네이티브 `glassEffect`, 그 외에는 `Material` 대체 렌더링. |
| `GlassGroup` | OS 26에서 `GlassEffectContainer`로 감싸 가까운 글래스 모양이 서로 섞이게 합니다. 그 외에는 내용을 그대로 표시합니다. |
| `GlassButton`, `.buttonStyle(.liquidGlass)` | 세 가지 크기의 캡슐형 글래스 버튼. 눌림, 비활성, 파괴적 동작 상태를 지원합니다. |
| `GlassCard` | 글래스 위의 여백 있는 컨테이너. |
| `GlassTextField` | 선택적 SF Symbol과 포커스 링이 있는 텍스트 필드. |
| `GlassSearchBar` | 지우기 버튼과 Cancel 버튼이 있는 캡슐형 검색 필드. |
| `GlassTabBar` | 모든 `Hashable` 선택 값에 대해 제네릭인 떠 있는 탭 막대. 빌더는 `if`와 `for`를 지원합니다. |
| `GlassNavigationBar` | 왼쪽과 오른쪽 항목을 둘 수 있는 떠 있는 제목 막대. |
| `glassSheet(isPresented:material:content:)` | 떠 있는 하단 시트. 드래그, 바깥 탭, 손쉬운 사용의 이스케이프 제스처로 닫힙니다. tvOS에는 없습니다. |
| `GlassTheme`, `GlassRenderingMode` | 기본 머티리얼·모양·그림자와 대체 렌더링 강제를 위한 환경 값. |

## 아키텍처

- `Sources/LiquidGlassKit/Core`에는 값 타입 `GlassMaterial`, `GlassShape`, `GlassTheme`,
  `GlassRenderingMode`가 있습니다.
- `Sources/LiquidGlassKit/Surface`에는 `glassSurface`와 `GlassGroup`이 있으며, SwiftUI의
  글래스 API를 호출하는 곳은 여기뿐입니다.
- `Sources/LiquidGlassKit/Components`는 모든 컨트롤을 `glassSurface` 위에 만들기 때문에 테마와
  렌더링 모드가 모든 컨트롤에 적용됩니다.

`glassSurface`는 환경의 `GlassRenderingMode`를 `GlassRenderingMode.isNativeGlassAvailable`과
비교해 결정합니다. 이는 `#available(iOS 26, macOS 26, tvOS 26, watchOS 26, *)` 검사이며,
SwiftUI가 `glassEffect`를 사용할 수 없다고 표시한 visionOS에서는 항상 `false`입니다. 각 머티리얼은
두 경로 모두에 대응 항목이 있습니다.

| `GlassMaterial` | 네이티브 경로 | 대체 경로 |
| --- | --- | --- |
| `.clear` | `Glass.clear` | `.ultraThinMaterial` |
| `.frosted` | `Glass.regular` | `.thinMaterial` |
| `.tinted(c)` | `Glass.regular.tint(c)` | `.regularMaterial` + 색상 오버레이 |
| `.dark` | `Glass.regular.tint(black)` | `.ultraThickMaterial` + 검은색 오버레이 |

### 테스트

```bash
swift test                                                   # macOS
xcodebuild test -scheme LiquidGlassKit \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'   # iOS Simulator
```

Swift Testing 테스트 스위트는 머티리얼과 모양 로직, 테마 값 제한, 렌더링 모드 결정, 탭 빌더,
시트가 닫히는 임곗값을 다룹니다. 대체 경로의 오프스크린 렌더링은 모든 컴포넌트가 테마의 머티리얼로 글래스를
그리는지, 명시한 머티리얼이 테마보다 우선하는지, 어두운 글래스 위의 레이블이 흰색이고 파괴적 동작의 레이블이
빨간색인지, 시트가 표시되는 동안에만 배경을 어둡게 하는지, '투명도 줄이기'에서 불투명한 배경을 그리는지
확인합니다. CI는 macOS, iOS 26 시뮬레이터, 대체 경로만 있는 iOS 18.6 시뮬레이터에서 테스트를
실행하고, `Package.swift`의 모든 플랫폼용으로 라이브러리를 빌드합니다.

`ImageRenderer`는 블러를 캡처하지 못하고 네이티브 글래스도 일부만 캡처하므로, 테스트는 대체
렌더링의 색조와 그려진 영역, 그리고 각 컴포넌트가 네이티브 경로에서 대체 경로와 다르게 그려지는지를
확인합니다. 글래스의 최종 모습은 확인하지 않습니다.
