# Security Policy

LiquidGlassKit is a UI library: it draws views and does not handle network
traffic, storage or credentials. Security issues are unlikely, but if you find
one, please report it privately.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/muhittincamdali/LiquidGlassKit/security/advisories/new)
for this repository and include steps to reproduce and the affected version.
